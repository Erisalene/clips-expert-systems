# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Давиденко Федір Андрійович
- Група: ІН-33

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – префіксні вирази та обчислення в правилах;
- `README.md` – опис проєкту.

## Висновки
Під час виконання лабораторної роботи було освоєно базові принципи роботи з системою контролю версій Git та хмарним сервісом GitHub. Створено структурований репозиторій для зберігання програмного забезпечення експертних систем, розроблених у середовищі CLIPS IDE. Організовано розміщення файлів за папками (Lab1 – Lab5) та оформлено супровідну документацію мовою Markdown. Практична реалізація показала важливість належного документування й версіонування коду при розробці інтелектуальних систем.
